        Publishing to GitHub

        Publishing saves recipes to your website's GitHub repository. It needs a personal access token, which is stored only in this browser.

        1. Open GitHub → New fine-grained token.
        2. Name it "Recipe Studio" and pick an expiration.
        3. Under Repository access, choose Only select repositories → allisonchen23.github.io.
        4. Under Permissions → Repository permissions, set Contents to Read and write.
        5. Generate the token and paste it below.
